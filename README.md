\# RUL Predictive Maintenance



基于机器学习的工业设备剩余寿命预测项目。



\## 1. 项目背景



本项目计划基于 NASA C-MAPSS 涡扇发动机数据集，

探索工业设备剩余使用寿命（RUL）预测方法。



\## 2. 项目目标



\- 学习工业时序数据处理

\- 掌握特征工程方法

\- 使用机器学习算法进行 RUL 预测

\- 完成模型评估与部署



\## 3. 技术栈



\- Python 3.11

\- NumPy

\- Pandas

\- Scikit-learn

\- XGBoost

\- FastAPI

\- Docker
